# 18 — سياسة تغيير المستودع (Repository Change Policy) (F-10)

> **النطاق:** Documentation Policy فقط (F-10). لا حذف ولا نقل ولا إعادة تسمية
> لأي ملف/مجلد موجود، ولا تعديل كود/ترحيلات/APIs/schema/tests، ولا خطة جديدة،
> ولا F-11.
> خريطة مصادر الحقيقة: `docs/00-OVERVIEW.md`. الحوكمة: `docs/11-DEFINITION-OF-DONE.md`.
> الخطة الحالية: `docs/15-ROADMAP.md`. التصحيحات: `docs/16-KNOWN-ISSUES.md`.
> سياسة الـ dot-folders التفصيلية: `docs/17-DOT-FOLDERS-POLICY.md` (F-9).

## 1. القاعدة (ملزمة لكل Agent لاحق)

ممنوع على أي Agent إضافة **أي ملف أو مجلد** إلى المستودع خارج نطاق المهمة
الموكلة إليه دون إذن صريح موثّق.

الملف الجديد مسموح فقط عبر أحد المسارين:

1. **داخل النطاق ومبرَّر بوضوح** — الملف لازم لتنفيذ المهمة الموكلة، ويُذكر
   تبريره في تقرير المهمة (`PLAN-STATUS.md` + `WORKLOG.md`)، أو
2. **موافقة صريحة** — إذن موثّق مسبقًا يغطي الملف/المجلد خارج النطاق.

## 2. ما تشمله السياسة خصوصًا (أمثلة ملزمة، لا حصرًا)

الإنشاء **غير المصرح به** ممنوع لكل مما يلي متى كان خارج نطاق المهمة:

- ملفات التخطيط ونسخ الخطط.
- مجلدات Agent artifacts وأي dot-folder / artifact مشابه
  (`.agent/`، `.claude/`، `.gemini/` وأشباهها — الجرد الكامل في `docs/17` §2).
- التقارير المؤقتة.
- ملفات الاختبارات المؤقتة.
- أدوات شخصية للوكيل.

ملاحظة: القائمة أعلاه تمنع الإنشاء **خارج النطاق** فقط — ملف تتطلبه المهمة
فعلًا (كمثال: ترحيل جديد لمهمة أقرّته) يبقى مسموحًا عبر المسار (1) أعلاه.

## 3. العلاقة مع F-9 (لا تعارض ولا توسع خفي)

- F-9 وثّق الـ dot-folders والـ agent artifacts **الموجودة** ومنع إنشاء نسخ
  جديدة منها دون إذن (`docs/17`).
- F-10 **يُعمِّم المبدأ** ليصبح سياسة تغيير عامة على أي ملفات أو مجلدات
  جديدة خارج نطاق المهمة، وليس dot-folders فقط.
- لا تعكس هذه السياسة أي قرار بحذف أو نقل أي artifact موجود حاليًا —
  الموجودات تُحفظ كما هي حتى قرار منفصل خارج F-10.

## 4. الربط بمصادر الحقيقة (F-8)

- `docs/00-OVERVIEW.md` — خريطة مصادر الحقيقة (A–G)؛ هذه الوثيقة (`docs/18`)
  تفصيل تنفيذي مكمل لها لبند انضباط التغيير فقط.
- `AGENTS.md` — تعليمات الوكلاء؛ التطبيق عبر قاعدة "تغيير المستودع" في
  «قواعد سريعة»، وتُقرأ هذه السياسة مع قائمة "اقرأ أولاً" ولا تستبدلها.
- `docs/17-DOT-FOLDERS-POLICY.md` — التفصيل الخاص بـ dot-folders؛ هذه الوثيقة
  تعميمه ولا تلغيه.
- `docs/15-ROADMAP.md` — الخطة الحالية؛ لا تُنشئ هذه الوثيقة خطة جديدة ولا
  تُنفّذ F-11.
- `PLAN-STATUS.md` + `WORKLOG.md` — حالة وسجل F-10 فقط.

## 5. تأكيدات النطاق (F-10)

- لم يُحذف أو يُنقل أو يُعَد تسمية أي ملف/مجلد موجود في هذه المهمة.
- لم يُنشَأ أي dot-folder أو agent artifact جديد في هذه المهمة
  (الملف الجديد الوحيد `docs/18` داخل `docs/` وضمن نطاق التوثيق).
- لم يُعدَّل أي source code (`src/`) أو migration/schema أو API behavior
  أو test في هذه المهمة.
- لم تُتَّخذ أي architectural decision جديدة في هذه المهمة
  (OOP/MVC/Separation of Concerns/i18n محفوظة — لم تُلمس).
- لم يُنفَّذ أي جزء من F-11 في هذه المهمة.
